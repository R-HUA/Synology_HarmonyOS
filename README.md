# NAS 工作台

HarmonyOS 原生 NAS 客户端，手机直接通过 HTTPS 连接群晖 DSM。

使用 API 26 Stage 工程和 ArkUI V2，手机直接连接 NAS。主界面分为首页、文件、任务、设置，从首页进入独立的 Synology Drive 或照片模块，底栏随模块切换，登录会话由 Asset Store 加密保存；文件浏览、整理和传输使用真实的 File Station 接口。照片页提供按拍摄时间浏览的缩略图库、空间与相册切换、多选操作、详情和原文件读取；手动上传与相册备份使用 Photos 接口。底部使用原生悬浮页签，图库列数随当前内容区域宽度调整。

## 使用流程

1. 在登录页填写 NAS 地址、账号和密码；协议根据地址自动识别，未填写协议时默认使用 HTTPS。加密连接可选择忽略证书校验，危险连接在登录前确认当前地址的风险。登录或会话校验成功后自动保存历史，退出账号保留历史；地址栏右侧可打开历史登录并移除记录，页面不提供手动添加或编辑地址。连接配置读取失败时可重试，确认损坏后可保留原文件并重建。危险策略仅用于同一地址，旧记录中未经确认的策略须重新确认。
2. 在文件页进入共享文件夹，可新建文件夹、重命名、复制、移动或删除条目。复制和移动先选择来源，再浏览到目标目录确认；同名冲突不自动覆盖。共享目录本身不可整理。每次整理先保存操作记录，再提交请求；结果待确认时按记录中的源和目标核对。有服务端任务标识的记录可继续查询，没有标识的记录需人工核对后关闭，重新启动应用后仍可查看。
3. 在目标目录点击标题栏“上传与新建”按钮选择上传，通过系统文件选择器授权读取文件。在文件操作菜单中下载文件到应用离线区，再到任务页将已完成的下载另存到系统文件目录。
4. 在任务页切换“传输任务”和“文件整理”，查看进度、校验与失败原因；传输任务可按待处理或已结束筛选。任务记录按 NAS 地址和账号隔离，重启后核对原系统任务。队列读取失败时暂停新增传输，点击“重新加载”成功后恢复。结果待确认的上传不会自动重发；在 NAS 核对后可关闭记录，再自行决定是否重新选择文件上传。已结束的传输可清理记录和本机私有副本，下载文件应先另存。
5. 从首页进入照片模块，在“照片 / 相册 / 共享 / 更多”中切换视图，并选择个人空间、已启用的共享空间或“与我共享”，按时间线浏览，或打开相册；点击“加载更多”继续追加。打开照片可查看预览与详情，读取原图或原视频后可另存。原文件读取在当前页面进行，单项上限 256 MiB；动态照片目前展示静态预览。空间未启用或无权限时会显示读取错误。
6. 照片页右上角“更多”提供“选择”和“上传”。选择后可批量共享、添加到相册、删除、移动、复制或下载原文件到系统相册；共享生成一个相册链接，移动和复制跳过同名冲突。添加到相册和创建共享链接限个人空间，“与我共享”只读。点击上传直接打开系统照片选择器，确认选择后立即开始上传，不进入独立上传页；每批最多 20 项、单项 256 MiB、总计 512 MiB，无需选择目标路径；上传到个人空间 `Photos/PhotoLibrary/年/月`，日期优先取拍摄时间，缺失时取文件修改时间，缺失的目录由 Photos 文件夹接口逐级创建。同批重名加序号，NAS 已有同名内容由 Photos 重命名保留。失败时显示错误，重新选择不会重复提交仍在队列中的同一项目。照片任务入口同时显示手动上传和自动备份，结果以任务页确认状态为准。
7. 在其他应用中分享文件到 NAS 工作台，登录后进入文件页选择目标目录，再确认上传。分享收件箱一次最多 20 个文件、单个 256 MiB、合计 512 MiB；当前待确认内容仅保留在本次进程中，进程结束后需重新分享。
8. 文件操作中的“创建分享链接”可设置口令、可用日期与过期日期；首页或文件菜单中的“我的分享”可分页查看、编辑和撤销链接。编辑时明确选择保留、设置或移除口令，口令只在短期输入状态中保留，复制链接与复制新口令是独立操作。撤销分享不删除原文件。
9. 从首页或任务页进入“NAS 下载”，查看 Download Station 任务，选择 NAS 目录并确认后提交 HTTP(S)、FTP 或 magnet 链接。套件会话需要验证时，可在下载页面输入当前账号密码及新的动态码，保留主会话与已有任务，验证完成后自行重新确认操作。该下载由 NAS 执行，不下载到手机；列表以统一紧凑行显示标题、进度、大小、采样速率与状态，下载中不放大卡片。可查看详情、暂停、恢复或移除任务；移除任务时未完成数据的处理由套件决定。
10. 从首页进入“全部套件”，查看已安装套件的名称、版本和状态，按名称或标识搜索，或筛选“本应用支持”。打开详情可刷新当前状态，并进入已有文件、Drive、照片或 NAS 下载功能；其他套件可在浏览器中打开当前 NAS 地址。目录只在打开或手动刷新时读取，缓存仅保留在本次连接中，刷新失败保留已有内容和读取时间。当前账号无权读取目录时，仍可使用已授权的业务功能。
11. 从首页“更多功能”进入容器，查看名称、状态、镜像，以及详情中的概览、资源、挂载、端口和日志；列表支持名称搜索与状态筛选。日志手动读取，也可开启每 5 秒跟随，滚动查看、离页或进入后台即停止，最多保留 500 行或 512 KiB。
12. 云同步按连接查看服务商、脱敏账号、同步目录及方向、状态、错误与历史，容量缺失时显示“未提供”。历史手动分页，每次 100 条，最多保留 500 条或 512 KiB。系统日志与笔记提供当前 NAS 浏览器入口。

从首页进入 Synology Drive，底栏显示“我的文件 / 团队文件 / 更多”。在“更多”中查看最近、星标、共享和回收站，也可进入 Drive 传输、文件操作记录、文件链接及通知。搜索从“我的文件”标题栏进入独立页面，返回后恢复原列表。Drive 与 File Station 文件列表滚动到底追加下一批。Drive 图片可直接查看原图，双击恢复显示比例；常见文档和音视频下载完成后调用系统预览，其他格式显示详情，下载由操作菜单明确发起。模块视图切换保留目录和列表；照片页保留空间、相册和分页，退出账号时清除这些状态。读取与传输期间仍可切换页签。系统返回先关闭浮层和详情，再返回模块内的上级，最后回到进入前的全局页签；标题栏“返回”可直接退出模块。

在设置页“模块底栏”中，可将 Drive 的两个常用视图、照片的备份或传输入口加入底栏，最多 5 项；照片的共享可移到“更多”。设置保存在本机，不可用的功能自动隐藏。设备信息、历史登录与系统控制也集中在设置页。

在照片模块“更多”的“相册备份”中开启自动备份，可选择继续上次备份、仅备份新照片或备份所有照片；默认关闭。备份设置和成功记录按 NAS 与账号保存。默认位置为个人空间 `Photos/MobileBackup/手机型号`，也可选择自定义文件夹；目录可按年/月、来源相册或直接保存到备份根目录。上传设置包含仅备份照片、仅限无线局域网和仅充电时，默认包含视频、仅限无线局域网、不限制充电。成功记录包含内容摘要和目标目录，内容或目标变化后可再次备份；结果未知的上传不会自动重传。

自动备份需要 `READ_IMAGEVIDEO` 全图库读取权限，须完成受限权限审批并在签名 Profile 中授权。应用启动、回到前台和图库变化时扫描，条件不满足时等待；每次只暂存一项文件。系统已接管的上传可继续执行，应用进程终止后不会持续扫描，重新启动后核对原任务。当前不提供动态照片组合转换。

同一账号一次只允许一组写入；其他模块存在进行中或结果待确认的写入时，先处理已有任务。读取和下载仍可使用，批量上传依次启动。写操作的网络超时不代表服务器未执行。出现“结果尚未确认”时，应先刷新目录核对。账号权限由 NAS 最终判断，能力发现只说明接口可用。主动退出账号会先停止该账号尚未完成的系统传输；已经写入 NAS 的内容不会因退出或取消任务而自动删除。

照片媒体通过同源认证请求写入应用私有缓存，不把登录或分享凭证放入界面图片 URL。缩略图并发最多 3 项，缓存上限为 60 项、24 MiB；详情正在使用的预览保留到页面关闭。原文件会检查 HTTP、业务错误、内容类型、文件头及长度，无法确认时不提供另存。Photos 接口属于套件内部接口，套件升级后应重新核对当前账号的可用范围。

## 分享与 NAS 下载边界

File Station 分享采用 Sharing v3；Download Station 列表与控制选择客户端支持的 v1/v3 和服务端范围的交集，带链接与目标目录的创建仅使用 v3。仅支持旧版本的服务器仍可读取和控制已有任务，不尝试使用官方旧示例中的 v1 创建参数。新增套件与账号权限分别验证，不能由 API 发现直接推断“已安装”或“已授权”。

分享链接保留服务端返回的地址，不改写为 DSM origin、不携带管理会话、不后台访问外部链接；不安全链接会拒绝复制或分享。分享日期按 NAS 的日期规则生效，手机不自行转换日期或计算链接过期状态。

每次扩展修改先将待确认标记持久化到对应 NAS/账号的私有目录。记录只包含功能、操作和时间，不保存下载 URI、分享口令或登录凭据。响应不明确、网络中断或退出进程时保留标记并阻止重复提交；可以继续刷新列表，确认实际结果后手动关闭标记。创建 NAS 下载成功但没有任务 ID 时，当前版本要求人工核对列表或 DSM，不按标题或相同大小自动关联任务，也不虚构远端 ID。记录读取或保存失败时不发送新的修改。

分享和 NAS 下载列表当前按页面进入或用户刷新采样，不做后台轮询；隐藏页面不会停止 NAS 下载。未知大小不显示假百分比，未知状态明确显示待核对，做种单独标识。手机传输同样使用紧凑列表，完整错误、另存和核对关闭操作保留在任务详情中；当前手机传输提供取消，不以“暂停”文案代替取消。

## 本地开发

开发工具链：DevEco CLI `1.3.0-stable`，HarmonyOS SDK `26.0.0.105 Release`；最低支持版本和目标版本均为 `26.0.0`。含本机签名配置的 `build-profile.json5` 不纳入版本管理，新环境从无签名模板复制后配置自己的签名。

```powershell
Copy-Item build-profile.template.json5 build-profile.json5 # 仅新环境初始化
devecocli build
./scripts/test-core.ps1
```

配置签名后构建产物为 `entry/build/default/outputs/default/entry-default-signed.hap`，未配置签名时为 `entry-default-unsigned.hap`。测试脚本复用本机 SDK 的 TypeScript 编译器，再使用 Node 内置测试运行器；没有额外 npm 依赖。SDK 安装在其它位置时传入 `-SdkRoot`。

CLI 或守护进程异常时，可使用 DevEco Studio 自带的 Node 与 Hvigor；按实际安装目录设置 Java 和 SDK，并明确指定产品和构建模式：

```powershell
$env:JAVA_HOME = 'D:\Program Files\jdk21'
$env:DEVECO_SDK_HOME = 'D:\Program Files\DevEco Studio\sdk'
& 'D:\Program Files\DevEco Studio\tools\node\node.exe' `
  'D:\Program Files\DevEco Studio\tools\hvigor\bin\hvigorw.js' `
  assembleHap --mode module -p 'module=entry@default' -p 'product=default' -p 'buildMode=debug' --no-daemon
./scripts/test-core.ps1 -SdkRoot 'D:\Program Files\DevEco Studio\sdk\default'
./scripts/lint.ps1 -NativeLogPath "$env:USERPROFILE\.codelinter\arkPerfCheck.log"
```

发布模式将 `buildMode=debug` 改为 `buildMode=release`。Linter 以完整报告和本次原生日志中的扫描文件数判断结果，不能只看 CLI 退出码。构建、代码检查和设备兼容性分别验收，当前证据见 [验证记录](IMPLEMENTATION_VALIDATION.md)。

```powershell
# 只读、无凭证的 HTTPS/API 发现
./scripts/probe-nas.ps1 -Address https://nas.example.com:5001

# 本机弹窗输入凭证：登录 → 读取共享目录首批 → 登出
./scripts/probe-nas.ps1 -Address https://nas.example.com:5001 -Login

# 已启用 OTP 时，额外在本机输入动态码
./scripts/probe-nas.ps1 -Address https://nas.example.com:5001 -Login -WithOtp
```

诊断脚本不执行上传、覆盖或删除。结果位于已忽略的 `work/diagnostics/latest-probe.json`，只保存能力表、检查状态、文件数量和错误类别/数值；不保存账号、密码、SID、SynoToken 或文件名。账号需具备 File Station 权限。

应用中填写最终 HTTPS origin（允许自定义端口），先连接再输入账号密码。默认保留系统 TLS 校验并拒绝自动跳转；密码仅暂存内存以完成 OTP，成功登录或断开后清除。登录会话保存到 Asset Store 加密 Secret，包括 NAS 地址、账号、SID 与 SynoToken，不保存密码、不跨设备同步。再次启动通过受保护的 File Station 列表验证会话，通过后才进入已登录状态并恢复任务；没有该读取接口时要求重新登录。网络故障保留会话供重试，明确失效时清除并要求重新登录，主动登出清除本地保存并尝试服务器登出。认证请求通过内存 Cookie `id` 和 `X-SYNO-TOKEN` 请求头发送，不把会话凭证放入 URL 或业务表单。文件列表每次读取最多 100 项，滚动到底继续追加，以真实逻辑路径访问目录。

File Station 传输由系统 `request.agent` 执行，应用在启动任务前保存任务 ID，普通记录不保存 SID、Cookie 或密码；系统传输仍使用系统证书校验，不继承连接地址中的跳过证书策略。Photos 在已确认忽略证书校验的加密连接下复用当前连接流式上传，需要应用进程存活；其他连接使用系统任务。Drive 根据接口和连接方式选择前台、系统托管或应用后台传输，应用后台传输不能保证进程退出后继续执行。正常上传检查业务响应和远端大小；正常下载检查 HTTP 响应及实际文件大小。若 File Station 任务在进程退出期间完成，系统报告完成但缺少响应证据，应用通过 MD5 接口和本机分块摘要核对完整内容；核对通过显示“上传内容已核验”或“下载内容已核验”，不会补造丢失的业务响应。校验接口不可用、文件内容不符或证据仍不足时不报告成功。同名同大小不作为成功依据。系统任务恢复不等于 File Station 支持任意字节续传。

File Station 传输使用非计费、非漫游网络；Photos 上传按备份设置选择网络，手动上传不限制为无线局域网。文件先保存至应用私有空间，下载完成后可导出；私有复制、前台下载、照片原文件和系统下载共用剩余空间预留，另保留 32 MiB 余量，空间不足时拒绝启动。清理任务会移除该任务的私有副本，不删除 NAS 文件或已另存的文件。清理中断后会在下次加载时继续，避免留下占用队列额度的无效记录。下载 HTML 或具有 DSM 错误响应形状的 JSON 时，需有匹配文件名的附件响应头或与 NAS 一致的完整内容摘要才能区分用户文件与错误页面；无法确认时拒绝导出并显示原因。通过内容核验恢复的下载在导出前再次计算本机摘要。

Photos 每页读取最多 20 项。“与我共享”按服务端提供的照片来源选择媒体接口，缺少来源时显示原因，不猜测权限或接口。分享访问凭证仅保存在当前账号的内存中并随认证 POST 发送，不进入 URL 或普通存储；媒体缓存按实际来源和当前相册访问隔离。此适配使用套件内部接口，版本变更或套件拒绝会话时明确报告错误，并先核对文件会话，避免误报整个 NAS 登录失效。Photos 上传需要套件上传及文件夹接口，缺少上传回执时保留待确认结果，不以 File Station 校验代替 Photos 成功证据。

## 代码位置

- `entry/src/main/ets/features/fileSharing/`：NAS 外链的协议、分页列表、详情、编辑与撤销，独立于外部文件收件箱。
- `entry/src/main/ets/features/downloadStation/`：NAS 下载任务、链接与目录校验、逐任务结果和紧凑列表。
- `entry/src/main/ets/features/extensions/`：扩展能力状态、账号生命周期隔离和持久化待确认操作。

- `entry/src/main/ets/core/domain/DsmProtocol.ts`：边界校验、响应解析与错误分类。
- `entry/src/main/ets/core/network/`：DSM RPC 请求、已验证 API 版本选择、会话与 rcp 原生传输。
- `entry/src/main/ets/core/capabilities/`：按实际读取证据记录功能状态，区分权限、连接、版本与响应格式问题。
- `entry/src/main/ets/platform/`：UTF-8 解码、记录持久化、摘要及系统托管传输边界。
- `entry/src/main/ets/features/connection/`：V2 ViewModel、加密会话保存、持久文件整理任务，以及保留的可行性验证实现。
- `entry/src/main/ets/features/transfers/`：用户文件传输、持久记录、系统任务对账和导出。
- `entry/src/main/ets/features/photos/`：分页图库、详情、认证媒体缓存和原文件另存。
